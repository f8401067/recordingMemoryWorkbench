# 2026-11-02

## 暂停状态 LED 微亮（+ 修 LED 极性反了的老 bug）

- 用户反馈：暂停录音时绿 LED 太亮，要"微亮"。
- 查原理图（L2 双色 LED）：绿光阳极经 R3(24K) 接 3V3，阴极接 GPIO3，
  **是低电平点亮**；而 app_config.h 里 `LED_ACTIVE_LOW` 一直写成 0（高电平点亮）。
  结果 `ui_led(LED_OFF)` 反而把灯拉亮了——监听/暂停时灯常亮就是这个原因。
- 修：`LED_ACTIVE_LOW = 1`；`ui.c` 的板载 LED 从 GPIO 直驱改成 **LEDC PWM**
  （timer1/channel1、20kHz、10bit，避免和蜂鸣器 timer0/ch0 冲突），
  新增 `led_set_pct()` 按"看起来的亮度"算占空比（低电平点亮要反算）。
- 新增 `LED_DIM` 模式 + `LED_DIM_PERCENT`（默认 8%）；`enter_paused()` 从
  `LED_OFF` 改成 `LED_DIM`。深睡/关机前仍是 `LED_OFF`。
- IO 扩展板（BOX3 等）的灯没有 PWM，led_set_pct 里按 >50% 开/关兜底。
- 编译 0 警告，固件 0x164280（21% 余量），已烧录。
- 待用户确认亮度观感：若太暗调大 LED_DIM_PERCENT，若反而更亮说明极性判断反了。

### 跟进：8% 看不见，调到 40%
- 用户反馈暂停时"看不到亮光"。原因：R3=24K 限流下满亮也就 ~50µA，8% 占空比平均几微安，肉眼不可见。
- `LED_DIM_PERCENT` 8 → 40，重新烧录。
- `pm_pause_mode()` 加了状态日志：`电源模式：paused=?, light_sleep=?, usb=?`。
  实测插 USB 时 usb=1 → light_sleep=0（PWM 正常跑）；拔 USB 用电池时
  light_sleep=1，LEDC 会停振、引脚保持冻结电平——"微亮"可能变成时亮时灭/不亮。
  若用户在电池下也要求可见，方案：暂停时不进 light sleep（功耗 <0.3mA → 18mA），
  或改成"心跳"脉冲（每 2~3 秒短闪一下，light sleep 下也能看到）。
