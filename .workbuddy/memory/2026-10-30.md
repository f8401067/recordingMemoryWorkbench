## 第二轮：连接池 / Alembic 迁移 / 配置自动跟随 / 内置 PG compose / 数据搬家脚本

用户确认「12345 都做，SQLite 保留（方便推广体验）」，即做连接池、迁移化、切换健壮性、内置 PG、真迁移工具。

- **连接池**：`PostgresBackend` 懒创建 `psycopg_pool.ConnectionPool`（min 0 / max 8），`PgConn(raw=..., release=...)` 借用/归还；

  `db.reconfigure()` 换后端时关旧池。**坑**：只读查询不 commit 会让连接停留在 INTRANS，
  关池时报 "rolling back returned connection" 且长期占用快照 → `all_/one` 里读完补 `conn.commit()`。
- **Alembic 迁移**：删掉 `app/schema.sql` 与 `db._migrate()`，改 `app/migrations/versions/0001_initial.py`（幂等：建表 + 老库补列 + 建索引）。
  `alembic.ini` 放 server-py 根（**Dockerfile 必须 COPY 这个文件**，否则容器里迁移找不到配置）。
  `app/db_migrate.py` 提供 `run_migrations(cfg=None)`，用 `sqlalchemy.url` 把连接信息传给 env.py；
  **坑**：ConfigParser 插值 → URL 里的 `%` 要写成 `%%`；**坑 2**：`idx_device_code` 依赖 `devices.code`，
  建索引必须排在后补列之后，否则老库升级报 no such column。
- **配置自动跟随（替代"重启进程"）**：`db._maybe_reload()` 每 ≥1s 检查 `data/config.json` 的 `(mtime_ns, size)`，
  变了就 `reconfigure()`；用 `RLock` + `_reloading` 标记避免 get_conn→reconfigure→init_db→get_conn 递归。
  多副本共享同一 data 卷时各副本 1 秒内自动跟上，不需要重启。
- **compose**：新增 `docker-compose.postgres.yml` 叠加文件（`docker compose -f ... -f ... up -d`），
  postgres 服务 + 给 recall 注入 `DATABASE_URL` + `depends_on: service_healthy`。
- **数据搬家**：`app/tools/migrate_sqlite_to_pg.py`（`python -m app.tools.migrate_sqlite_to_pg --url ... [--dry-run|--force]`）：
  按外键顺序逐表复制、先跑迁移对齐结构、目标非空则拒绝、导完校验行数。
- 验证：fresh/老库/缺列老库三种 SQLite 升级、PG 建库+迁移+并发池、外部改 config.json 自动切换、

## ⚠ 事故：data/recall.db 损坏（recordings 表页被覆盖）

## ESP32-C3 / S3 录音笔固件（esp32/，新增）
- 目标：适配已有 `/api/open/*` 硬件接入协议，实现"长按录音 → VAD 跳静音 → Opus 压缩 → 先存 Flash → 按需上传 → 触发转写+纪要"。
- 技术选型：ESP-IDF（非 Arduino）+ `espressif/esp_audio_codec` 的 OPUS 编码 + `joltwallet/littlefs`；**两个 target 均编译通过**（IDF v6.1，S3 821KB/45%占用，C3 869KB/55%占用）。
- 关键实现：16k/20ms 帧 VAD（能量×自适应噪声底 + 过零率 + 600ms 拖尾）；自写 Ogg 封装 `ogg_mux.c`（Ogg page/CRC32 poly 0x04C11DB7/OpusHead pre-skip 312/granule 48k），已用 ffmpeg 参考文件往返验证，解码 PCM 相关系数 1.0000。
- 省电：深睡(10~60µA)+按键 ext1/GPIO 唤醒、麦克风可 GPIO 断电、VAD 不写静音、esp_pm 80/160MHz DFS、WiFi 仅上传时开+modem sleep、15s 一段落盘。**深睡与 `RECALL_AUTO_SESSION` 互斥**（常驻监听不深睡）。
- UI：长按 0.7s 开始/结束；三种屏幕配置（无屏 LED+蜂鸣 / SSD1306 I2C / ST7735 SPI），画布固定 128x64，5x7 点阵字库由 `tools/gen_font.py` 生成。
- 坑：IDF v6.1 无内置 cJSON（改手写 JSON 取值）、无 strlcpy、C3 不支持 ext1 wakeup（走 `esp_sleep_enable_gpio_wakeup`）、`#if PIN == GPIO_NUM_NC` 对枚举无效（引脚改用纯数字宏）、`idf.py build` 前必须先 `set-target` 否则 build.ninja 报 rules.ninja 缺失。
- 未验证：无真板子，电流为估算；MIC_SHIFT/ST7735 初始化序列需按实物微调。
