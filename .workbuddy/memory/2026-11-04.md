## 纪要编辑与分享（2026-11-05）
- 编辑原本就有：`PATCH /api/summaries/{id}` + SummaryDetail 的 markdown/标题编辑态（⌘S 保存）。
- 新增 `web/src/components/ShareSummary.tsx`：底部弹层，三项 —— 复制 Markdown / 下载 .md / 生成长图（预览 + 保存 + 系统分享 + 复制图片）。
- 新增 `web/src/lib/poster.ts`：`summaryToPosterHtml` 拼长图 HTML（720px 宽，自带 `.rp-*` 样式注入到 head），`htmlToPng` 用 **html2canvas** 渲染成 2 倍 PNG（新依赖）。
- ⚠ 关键坑：不要用 SVG foreignObject 方案（dom-to-image/html-to-image 那套）——
  这个 Chromium 里 `<img>` 加载含 foreignObject 的 SVG 后 canvas 被判 **Tainted，toBlob 直接抛错**。
- ⚠ html2canvas 排版坑：它自己算文字行框，**不认 padding-left / text-indent / 绝对定位 / flex** 的缩进，
  列表圆点必须写成「`li > span.rp-li(display:block;margin-left:16px)` + 圆点 `float:left;margin-left:-16px`」，
  否则折行和第二行会贴在左边、圆点压字。验证方法：生成 PNG 后用 PIL 量每行最左暗像素。Markdown 的 list-style 圆点它也不画，得手动塞 `<i class="rp-dot">`。
- 超长内容按画布像素上限（约 1600 万）自动降采样，避免 iOS Safari 画不出来。
